# Métodos de Ordenamiento en Python
Este repositorio contiene la implementación en Python de cuatro algoritmos de ordenamiento avanzados, desarrollados para la materia de Estructura de Datos. Además, incluye un programa principal con menú interactivo por consola que permite ingresar una cantidad personalizada de números y ordenarlos mediante el método seleccionado.
## Contenido del repositorio
* **shellsort.py**: Implementación del método ShellSort mediante reducción sucesiva de brechas (gaps).
* **quicksort.py**: Implementación recursiva del algoritmo QuickSort utilizando partición basada en un pivote.
* **heapsort.py**: Implementación del algoritmo HeapSort construyendo y reestructurando un montículo máximo (Max-Heap).
* **radixsort.py**: Implementación de Radix Sort no comparativo, ordenando valores enteros dígito por dígito.
* **menu_ordenamiento.py**: Programa interactivo por consola que solicita la cantidad de números, los valores a ordenar y el método a utilizar, repitiéndose hasta que el usuario elija salir.

### Flujo del programa:
1. Selecciona el método de ordenamiento deseado (1 al 4) o la opción 5 para salir.
2. Ingresa la cantidad de números que deseas ordenar.
3. Escribe los números (puedes ingresarlos todos en una sola línea separados por espacios o uno por uno).
4. El programa mostrará la lista original y la lista resultante ordenada.
